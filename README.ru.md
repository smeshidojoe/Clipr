# Clipr

[English](README.md) · **Русский**

Записывает часть экрана и превращает её в маленький чёткий GIF —
сразу готовый к вставке в чат через `Ctrl + V`.

</div>

## Скачать

1. Откройте страницу [Releases](https://github.com/SmeshidoJoe/Clipr/releases/latest).
2. Скачайте `Clipr-Setup-….exe` и запустите. Права администратора не нужны.
3. При первом запуске Clipr предложит скачать FFmpeg (около 80 МБ) — он и
   записывает экран. Соглашайтесь.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер»,
нажмите **Подробнее → Выполнить в любом случае**. Так бывает у любой программы
без платного сертификата подписи.

Работает в Windows 10 и 11.

## Как пользоваться

Clipr живёт в трее, рядом с часами. Внизу экрана — небольшая панель:

1. **Выберите область** — кнопка с уголками. Протяните рамку или просто
   щёлкните, чтобы взять весь монитор. Открыв выбор снова, область можно
   подправить: тяните её края, углы или всю рамку. Крестик у размера области на
   панели возвращает весь экран.
2. **Запишите** — красная кнопка. Пауза и стоп — на той же панели.
3. **Отредактируйте** — после остановки откроется редактор. Ручки на шкале
   обрезают по времени (видео показывает кадр под ручкой), рамка поверх видео
   кадрирует, её края и углы тоже тянутся. Колесо мыши приближает картинку к курсору, средняя кнопка
   сдвигает её.
4. **Экспорт GIF** (или `Enter`). GIF сохраняется и **копируется в буфер обмена
   файлом**, так что `Ctrl + V` в Telegram, Discord, Slack или Проводнике
   вставляет сам GIF. Об этом скажет плашка в углу экрана; щелчок по ней
   покажет файл. **Экспорт видео** (`Ctrl + Enter`) делает то же самое с MP4 —
   с той же обрезкой, кадром, размером и частотой.

Панель никогда не попадает в запись, хотя остаётся на экране.

| Сочетание | Работает в любой программе |
| --- | --- |
| `Ctrl + Alt + R` | начать / остановить запись |
| `Ctrl + Alt + P` | пауза / продолжить |
| `Ctrl + Alt + A` | выбрать область (когда панель открыта) |
| `Ctrl + Alt + X` | показать / скрыть панель |

В редакторе: `Пробел` — плей/пауза, `←` `→` — на кадр, `R` — сбросить кадр,
`Esc` — закрыть.

**Как сделать GIF меньше.** В редакторе уменьшите **Размер** (доля от записанной
области: 50 % от 752×648 — это 376×324) или **Кадры/с**. **Сжатие** уменьшает
файл ещё сильнее, но добавляет немного шума на ровных заливках, поэтому по
умолчанию оно выключено. GIF больше 50 кадров/с не умеет — на 60 видео сохранит
60, а GIF получит 50.

**Пресеты.** Кнопка слева от **Размера** выставляет размер, кадры/с и сжатие в
один клик. Чтобы сохранить свой, настройте значения и выберите **Сохранить
текущие как пресет…**.

Всё остальное — сочетания, папки, язык, автозапуск, запуск свёрнутой — в
**Настройках** (кнопка с ползунками на панели или меню в трее). Язык интерфейса
по умолчанию английский; русский — в Settings → System.

## Вопросы

**Где мои GIF?** В `Видео\Clipr`. Папку можно поменять в Настройки → Файлы.
Рядом с GIF может сохраняться исходное видео (по умолчанию включено) — из него
можно собрать GIF заново с другими настройками. Если вы экспортировали и видео,
у исходника в имени будет `_source`.

**Панель пропала.** Щёлкните по значку в трее или нажмите `Ctrl + Alt + X`. Она
всегда возвращается вниз по центру основного экрана.

**Мигает ли курсор во время записи?** Не должен: Clipr снимает через Desktop
Duplication, если область целиком на одном мониторе. Если в Настройки → Запись
выбран способ «GDI», курсор моргает — так устроен этот способ захвата.

**Где настройки?** В `%APPDATA%\Clipr`, там же скачанный FFmpeg. Незаконченные
записи лежат в `%TEMP%\Clipr` и убираются через сутки.

**Как удалить?** Параметры → Приложения → Clipr → Удалить. Удаление спросит,
оставить ли настройки и FFmpeg; ваши GIF не трогаются никогда.

## Для разработчиков

Python 3.13, PySide6, FFmpeg в `PATH` или скачанный из программы.

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

`Ctrl + C` в консоли закрывает программу. Сборка — из глобального Python, без venv:

```bash
pip install pyinstaller
```

```bash
pyinstaller --clean --noconfirm Clipr.spec
```

Потом откройте `clipr_setup.iss` в [Inno Setup 6](https://jrsoftware.org/isinfo.php)
и нажмите Compile — установщик появится в `installer_output`.

Версия живёт в одном месте — `APP_VERSION` в `clipr/constants.py`; spec и
установщик берут её оттуда. Для самообновления приложите к релизу на GitHub,
рядом с установщиком, zip с `Clipr.exe` внутри.

Как это устроено, коротко:

- Сначала запись в H.264 (`ddagrab`, при неудаче — `gdigrab`); пауза начинает
  новый сегмент, стоп склеивает их. GIF собирается только после обрезки, в два
  прохода палитры (`palettegen` + `paletteuse`, `diff_mode=rectangle`).
- Панель прячется от захвата через `WDA_EXCLUDEFROMCAPTURE`. Обычное прозрачное
  окно Qt — layered и этот флаг не принимает, поэтому панель и уведомления
  собираются через GPU (скрытый `QRhiWidget`): так работают и исключение, и
  сглаженные скруглённые края.
- Движение — по модели fluid interfaces Apple: пружины с затуханием и откликом,
  скорость отпускания переходит в пружину; токены — в `clipr/ui/motion.py`.

```
clipr/
  app.py            трей, горячие клавиши, состояние записи
  ffmpeg.py         Recorder и GifExporter
  updater.py        самообновление из релизов GitHub
  i18n.py           строки на английском и русском
  ui/               панель, выбор области, редактор, настройки, уведомления
```
